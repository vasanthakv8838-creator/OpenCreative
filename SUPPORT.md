# Getting help with OpenCreative

Thanks for trying OpenCreative!

## Where to ask

- For a reproducible bug, [open a bug report](../../issues/new?template=bug_report.md).
- For an idea or missing capability, [request a feature](../../issues/new?template=feature_request.md).
- For general questions and open-ended conversations, use [GitHub Discussions](../../discussions) when the repository has Discussions enabled.
- For a code contribution, read [CONTRIBUTING.md](CONTRIBUTING.md).

## Help us help you

When asking for help, include:
- Which OpenCreative tool you were using.
- What you were trying to do.
- The steps that led to the problem.
- Your browser, version, device, and operating system.
- Any error message, with private information removed.

## Please protect your privacy

OpenCreative is designed around local-first workflows. Do not post private documents, personal data, passwords, API keys, or confidential media in public issues or discussions. Share a small sample only when you have permission to do so.

## Response expectations

OpenCreative is an independent community project. Responses may take time, and support is provided on a best-effort basis. Clear, respectful, reproducible reports help everyone.
