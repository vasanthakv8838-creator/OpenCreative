OpenCreative · browser-side test suite

Office interoperability regression tests

These checks create temporary XLSX and DOCX files in memory, then run them through the same export, import and verification helpers used by OpenCreative Writer and Sheets. Your saved workbook and local productivity data are not changed.

A connection to the configured public CDNs is required to load ExcelJS, SheetJS, Mammoth and JSZip. Serve this repository over HTTP(S), not file://.
