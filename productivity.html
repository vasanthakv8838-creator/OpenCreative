About this workspace

Independent and open source

OpenCreative is an independent project. This productivity workspace is original software and is not Google Workspace, Zoho Workplace or Microsoft 365.

Privacy and storage

Documents, tasks, notes, calendar events, sheet cells, forms and responses are stored in your browser's localStorage. They are not uploaded to an OpenCreative server. Anyone with access to this browser profile may be able to access this data. Clearing browser data can erase it, so export backups.

Current limitations

This release is single-device and single-browser. It has no login, cloud sync, realtime collaboration, email hosting, video meetings, online sharing or server-side database. Writer exports HTML/TXT; Sheets supports multiple worksheets, cell formatting, filtering, sorting, common formulas and CSV/XLSX; Calendar exports ICS. DOCX/XLSX/PPTX fidelity and external Google/Zoho/Microsoft integrations are not implemented.
